\# Sales Prediction Dashboard



\## Project Overview



This project predicts future sales using a Machine Learning model built in Python and visualizes insights using a Power BI dashboard. The system analyzes historical sales data and forecasts upcoming sales trends.



\## Objectives



\* Analyze historical sales data

\* Predict future sales using a regression model

\* Visualize insights with an interactive dashboard



\## Tools \& Technologies



\* Python

\* Pandas

\* Scikit-learn

\* Power BI



\## Project Workflow



1\. Data collection from a sales dataset.

2\. Data cleaning and preprocessing using Pandas.

3\. Feature engineering (extracting Month and Year from order date).

4\. Training a Linear Regression model to predict future sales.

5\. Exporting prediction results to a CSV file.

6\. Building a Power BI dashboard to visualize actual and predicted sales.



\## Features



\* Sales trend analysis

\* Future sales prediction

\* Interactive Power BI dashboard

\* Business insights for decision making



\## Files in This Project



\* `clean\_data.py` → Python code for prediction model

\* `sales\_prediction.csv` → Original sales dataset

\* `sales\_forecast.csv` → Predicted sales output

\* `dasboadpic.png` → Power BI dashboard screenshot
